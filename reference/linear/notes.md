# Linear — notes

Capture: `hero.jpg`, `tokens.json` (canvas `rgb(8,9,10)`, 72 pill elements, `Inter Variable`).

## What to look at
- Near-black canvas `#08090A`, panels one step up `#0F1011`, hairlines `rgba(255,255,255,0.08)`.
- Variable weights 510 / 590 instead of 400 / 600 — the signature softness.
- 64px headlines at 1.0× line-height: dense, technical, confident.
- Pill buttons everywhere on marketing; 8px controls inside the product.

## What to steal
- Three-tone grey system (`#F7F8F8` / `#8A8F98` / `#62666D`) instead of a full neutral ramp.
- Hover = border brightness, not shadow.
- Mono for metadata (`Berkeley Mono`, 11px, `+0.04em`).

## What not to copy
- Dense small-text UI without the keyboard affordances that make it fast.
